# HimachalRide.com

HimachalRide taxi & tour website.

## Project approach

The site will be built section-by-section. Common header and footer are already separated so changes can be made once and reflected across the site.

## Structure

- `index.html` — Homepage
- `components/` — reusable HTML components if we need them later
- `pages/` — inner pages
- `assets/css/style.css` — global styles
- `assets/css/components.css` — header/footer styles
- `assets/js/components.js` — common header/footer + mobile menu
- `assets/js/main.js` — page-wide JavaScript
- `assets/images/` — all client photos and brand assets

## Current brand direction

Light + dark premium Himalayan style:
- Deep forest green
- Warm off-white
- Charcoal
- Muted gold accent

The final logo will replace the temporary `HR` text mark.
